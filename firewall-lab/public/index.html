Firewall Lab

Build the rulebase. Enforce the policy.

A firewall is just an ordered list of rules. Traffic is checked top-down, first match wins, and anything that matches nothing is denied by default. Write ALLOW rules so the firewall enforces the policy below — without opening holes. (ISI 315 · Week 6)

▶ Quick start — run a demo in 3 clicks

  1. Click a preset below — it loads a rulebase and tests it instantly.
  2. Each request lights up: green = matches policy, red = a security hole (allowed something forbidden), amber = blocked something that should be allowed.
  3. Read the callouts in Results and discuss. (To build your own, use the rule form on the right.)

Suggested demo order: Leaky (a broad ALLOW opens holes) → Tuned (clean, default-deny does the rest) → Shadowed order (a broad DENY on top blocks legit traffic — order matters).
